# MCPied MC

[English](README.md)

Мод для NeoForge, Minecraft 1.21.1. Пока мир запущен, мод поднимает локальный сервер [MCP](https://modelcontextprotocol.io): ассистент может смотреть мир и менять его — блоки, сущности, предметы, команды, а также искать предметы и рецепты.

Сервер слушает только `127.0.0.1:47821`. С других компьютеров к нему не подключиться.

## Что нужно

- JDK 21
- Minecraft 1.21.1
- NeoForge 21.1.250

## Запуск клиента

В Windows:

```bat
run-client.bat
```

Или из корня проекта:

```bat
gradlew.bat runClient
```

В `gradle.properties` указан путь к локальному JDK 21. Если на вашей машине его нет, поменяйте `org.gradle.java.home` на свой JDK 21.

Клиент для разработки сам скачивает набор модов в `run/mods` и, если сохранение есть, открывает мир `test`. Другой мир: `gradlew.bat runClient -Pworld=MyWorld`. Без автозапуска мира: `gradlew.bat runClient -Pworld=none`.

Зайдите в мир. В чате будет адрес: `http://127.0.0.1:47821/mcp`.

## Подключение в Cursor

В настройках MCP проекта:

```json
{
  "mcpServers": {
    "mcpied": {
      "url": "http://127.0.0.1:47821/mcp"
    }
  }
}
```

Тот же адрес подходит любому клиенту MCP по Streamable HTTP. Старый канал SSE: `http://127.0.0.1:47821/sse`.

Инструменты работают, пока запущен встроенный или отдельный сервер. Если нужна точка отсчёта игрока, игрок должен быть в мире.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `list_players` | Игроки онлайн: имя, uuid, позиция, измерение, режим, здоровье |
| `list_nearby_entities` | Сущности в сфере, радиус не больше 96 |
| `get_entity_nbt` | Полный SNBT сущности |
| `edit_entity` | Дописать или заменить NBT сущности |
| `get_block` | Id блока, состояние и SNBT блок-сущности |
| `set_block` | Поставить один блок, со свойствами и NBT |
| `fill` | Залить область, не больше 32768 блоков, без NBT блок-сущностей |
| `set_block_nbt` | Изменить блок-сущность |
| `execute_command` | Одна команда от игрока или от сервера |
| `give_item` | Выдать предмет, при необходимости с NBT |
| `search_items` | Поиск предметов по моду, id или имени |
| `search_recipes` | Поиск рецептов |
| `get_recipe` | Один рецепт: тип, результат, ингредиенты |

`search_items` и `search_recipes` читают индекс, который строится при старте сервера. Мир они не обходят.
